2. Objetivo

Dar clareza ao dia do usuário

Criar uma plataforma web para planejar o dia, armazenar tarefas por usuário e acompanhar o progresso diário.

PlanejarRegistrar atividades por data, horário, categoria, prioridade, status e observações.
GuardarPermitir cadastro, login e armazenamento das tarefas vinculadas à conta.
MedirExibir quantidade de tarefas concluídas e porcentagem de progresso.

9. Firebase

Serviço que sustenta autenticação e dados

O Firebase permite criação de conta, login, sessão ativa, logout, persistência em nuvem e atualização automática das informações.

Por que é importante? Firebase Auth identifica o usuário com segurança. Firestore salva perfis, configurações, pastas e tarefas. onAuthStateChanged observa a sessão e onSnapshot sincroniza tarefas em tempo real.
10. Banco de dados

Dados separados por usuário

O Firestore organiza cada conta em um documento próprio, usando o UID gerado pela autenticação como chave principal.

usuarios/{uid} nome, email, avatarImage, folders, configuracoes, criadoEm usuarios/{uid}/tarefas/{tarefaId} title, date, time, priority, status, category, favorite, notes

17. Segurança

Cada usuário acessa seus próprios dados

O UID do Firebase Auth é usado para buscar perfil e tarefas dentro de usuarios/{uid}, mantendo contas separadas.

Cuidados técnicos escapeHtml protege a renderização contra HTML digitado pelo usuário. normalizeTask padroniza tarefas para evitar campos vazios. As próximas melhorias incluem regras de segurança Firestore mais rigorosas.
